# KampüsBul - Üniversite Kayıp Eşya Takip Sistemi

## Proje Tanımı

KampüsBul, üniversite öğrencilerinin kampüs içerisinde
kaybettikleri veya buldukları eşyaları paylaşabilecekleri
web tabanlı bir uygulamadır.

## Çözülen Problem

Üniversite kampüslerinde kaybolan eşyaların sahiplerine
ulaştırılması zor olabilmektedir. KampüsBul, kayıp ve
bulunan eşya ilanlarını tek bir platformda toplayarak
bu süreci kolaylaştırmayı amaçlamaktadır.

## Hedef Kullanıcılar

- Üniversite öğrencileri
- Akademik personel
- İdari personel

## Kullanılacak Teknolojiler

- Python
- Flask
- HTML
- CSS
- SQLite
- Git ve GitHub
- GitHub Projects

## Planlanan Özellikler

- [ ] Kayıp ve bulunan eşya ilanı oluşturma
- [ ] İlanları listeleme
- [ ] İlanları türüne göre filtreleme
- [ ] Eşya adına göre arama yapma
- [ ] Teslim edilen eşya ilanını kapatma

## Proje Yönetimi

Projenin geliştirme süreci GitHub Projects üzerinden
takip edilmektedir.
